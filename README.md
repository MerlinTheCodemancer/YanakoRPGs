# YanakoRPG Website

Um website moderno e responsivo para o desenvolvedor de jogos YanakoRPG, criado com Vue.js 3 e Vite.

## Características

- ✨ Design moderno com animações suaves
- 📱 Totalmente responsivo
- 🎮 Seção de jogos com banners interativos
- 🔗 Links para redes sociais
- 📊 Visualização de habilidades com barras de progresso
- 🎯 Link direto para o Pokédex do Desenvolvedor

## Tecnologias Utilizadas

- Vue.js 3
- Vite
- CSS3 com animações
- Font Awesome para ícones

## Como Executar

1. Instale as dependências:
\`\`\`bash
npm install
\`\`\`

2. Execute o servidor de desenvolvimento:
\`\`\`bash
npm run dev
\`\`\`

3. Abra o navegador em `http://localhost:5173`

## Como Fazer Build para Produção

\`\`\`bash
npm run build
\`\`\`

## Estrutura do Projeto

\`\`\`
src/

## Personalização

### Adicionando Links de Redes Sociais

Edite o array `socialLinks` no componente `App.vue` para atualizar os links das redes sociais.

### Adicionando Jogos

Edite o array `games` no componente `App.vue` para adicionar novos jogos com seus respectivos links.

### Ajustando Habilidades

Modifique o array `skills` para atualizar as habilidades e seus níveis de proficiência.

## Recursos Incluídos

- 📸 Foto de perfil usando `unnamed.gif`
- 🎮 6 botões de redes sociais (YouTube, Twitter/X, Bluesky, Steam, Documentação, Itch.io)
- 🎯 Seção de habilidades com: Arte, Design, Programação, Experiência, Marketing
- 🎮 Banners de jogos com links diretos
- 🔗 Botão especial para o Pokédex do Desenvolvedor (https://dokimon-quest-c2934b.gitlab.io/)
